# 项目完成状态：探索性研究 v1.0

## 已经形成的成果

真实数据的检查与整理已经完成；八对眼标识的样本身份已核对，但没有把它们冒充成逐样本表达数据。21 个预定义基因全部唯一匹配。表达热图、区域比值图、完整基因结果、文件指纹和独立计算复核已生成。另有六页英文研究报告、英文 README、中文修订计划和阅读指南。项目尚未上传 GitHub。

当前结论：公开表中的 10 个 rod 相关基因都是黄斑组值更高；11 个 cone 相关基因中，10 个是周边组值更高。OPN1LW 两组接近。去除三个 opsin 后，剩余八个 cone 基因方向仍一致。但这不代表显著差异或独立验证。

## 原假设需要修正的地方

“黄斑”和“中央凹”不能直接当同义词。原论文讨论了较大组织范围的取样及黄斑内的杆细胞。原先对 rod/cone 表达方向的直观假设过于简单。现有组织组估计不能单独证明观察结果由哪一种细胞组成或技术因素造成。

## 作为 GitHub 探索性项目，怎样算完成

1. 能说清问题：比较公开组织组估计中的 rod/cone 相关基因模式。
2. 能说明来源：GSE94437 原始压缩文件和 GEO 元数据，保存校验值。
3. 能解释方法：精确匹配基因、保留全部面板、算黄斑/周边比值并画图。
4. 能复核结果：脚本重新生成图表，独立复核对照原始文件通过。
5. 能承认限制：没有 donor 变异、显著性检验或细胞数推断；注释版本等来源细节仍不完整。
6. 能完整展示：报告、图、结果表、代码和 README 配套。

上述本地研究交付物已完成 v1.0。它适合作为可复现的本科计算分析案例，而不是已发表论文或已经证实的新机制。报告和说明使用了 AI 辅助起草与编码，需要你本人理解、检查并对最终提交负责。
