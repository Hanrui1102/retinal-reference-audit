# 修订研究计划：人类黄斑与周边视网膜 rod/cone 相关基因的探索性表达比较

## 研究问题

在 GSE94437 公开提供的组织组 FPKM 估计中，预先选定的杆状细胞和锥状细胞相关基因，在黄斑视网膜与周边视网膜之间呈现怎样的表达模式？

## 数据与修订理由

使用 GSE94437 的 processed genes.fpkm_tracking 数据。原研究的样本记录包含八个眼标识的十六个视网膜样本，但公开表达表仅提供组织组估计，不含逐样本表达值。因此本项目改为描述性、探索性比较，不再以八对 donor 的配对检验为研究方法。本文件为修订草案，不表示已经获得课程或导师审批。

## 分析方法

保留两个视网膜组，排除 RPE/choroid/sclera。沿用分析前已确定的 10 个 rod 相关基因与 11 个 cone 相关基因，逐一核对匹配、缺失、重复和状态。展示 log2(FPKM + 1) 热图，计算每个基因的黄斑／周边 FPKM 比值与其 log2 转换。保留原始注释与可重复运行脚本。

## 原假设与结果报告

原假设为 cone 相关表达偏向黄斑、rod 相关表达偏向周边。该假设用于提出问题，不用于筛选结果。无论方向是否符合预期，都报告完整预定义面板。修订是在已发现数据粒度限制后进行；首次描述性检查已显示部分模式与假设不同，不将本计划声称为预注册。

## 范围与限制

不做配对 t 检验、Wilcoxon、FDR 或 donor 层面的推断；不把基因作为 donor 重复；不进行两个组的样本 PCA。结果不能证明细胞数量差异、因果关系或在人群中的普遍规律。组织组估计缺少逐样本变异，FPKM 与 bulk 组织组成也限制生物学解释。
